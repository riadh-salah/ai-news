# ai-news

نشرة أخبار الذكاء الاصطناعي العالمية بالعربية — تُحدَّث كل 8 ساعات عبر أتمتة Cursor.

## المحتوى

- [`news/index.html`](news/index.html) — أرشيف جميع الإصدارات
- [`news/09-09-2026 -- 12-AM.html`](news/09-09-2026%20--%2012-AM.html) — أحدث إصدار (4 أخبار + أفكار ربح من AI)

## تسمية الملفات

كل إصدار يُسمّى بالتاريخ والوقت: `DD-MM-YYYY -- HH-AM/PM.html`
