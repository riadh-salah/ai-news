الخبر الأول

HappyRobot: 150 مليون دولار — يونيكورن جديد يُشغّل وكلاء AI في قلب عمليات المؤسسات!

تخيّل وكيلاً يتفاوض مع سائق شاحنة بالهاتف، يرسل إيميلات للعملاء، يملأ نماذج الشحن، ويُنسّق المواعيد — بينما فريقك يراقب لوحة تحكم واحدة. HappyRobot لا يبني chatbot للدعم؛ بل «Enterprise Superintelligence» يُنفّذ workflows متعددة الخطوات عبر الصوت والبريد والمستندات والويب. 150 مليون دولار Series C بقيادة Prysm Capital — وتقييم 1.2 مليار دولار.

في 4 أغسطس 2026، أعلنت HappyRobot عن جولة Series C بقيمة 150 مليون دولار بقيادة Prysm Capital وEurazeo، مع مشاركة a16z وBase10 وY Combinator وOrange وDeutsche Telekom (T.Capital) وKoch Disruptive Technologies. التقييم بعد الجولة: 1.2 مليار دولار — إجمالي التمويل ~200 مليون دولار.

المؤسسان Pablo Palafox (CEO) وLuis Paarup وJavi Palafox — ثلاثة مؤسسين إسبان بدأوا من computer vision ثم pivot إلى voice agents للوجستيات. اليوم HappyRobot يخدم أكثر من 150 عميل enterprise منهم DHL وUber وKuehne + Nagel وNaturgy وRepsol. الإيرادات نمت 5× منذ Series B، وnet dollar retention فوق 150% — مع 70%+ autonomous resolution في customer support.

المنصة تُمكّن المؤسسات من بناء ونشر وإدارة وكلاء يتعلمون من كل تفاعل — من logistics إلى insurance وenergy وtelecoms وairlines. Tech.eu وصف HappyRobot كـ «agentic AI for supply chains expanding into enterprise operations». للمبدعين العرب: كل freight broker وenergy utility وtelco في MENA يحتاج deployment partner — consulting وvoice agent customization وtraining datasets عربية فرصة ضخمة.

💡 كيف تربح من HappyRobot وثورة Enterprise Superintelligence؟

  • Operational AI deployment: نشر وكلاء للوجستيات والطاقة — 15000–80000 دولار/مشروع.
  • Arabic voice agent customization: تخصيص وكلاء صوت عربية للـ freight وutilities — 8000–45000 دولار.
  • Workflow automation consulting: تحليل processes وربط ERP/CRM — 10000–60000 دولار.
  • دورات «Enterprise AI Agents»: bootcamp للـ operations teams — 249–1299 دولار.

Zenity: 125 مليون دولار — حارس مليار وكيل AI قبل أن يُخترقوا بياناتك!

الوكلاء لم يعودوا chatbots — هم يستدعون أدوات، يُنفّذون كوداً، يصلون لقواعد البيانات، ويتخذون قرارات بصلاحيات حقيقية. Zenity يقرأ نية كل إجراء قبل تنفيذه — ويُتيح لفرق الأمن الموافقة أو التعديل أو الحظر في الوقت الفعلي. 125 مليون دولار Series C بقيادة Norwest — وإيرادات تُثلَّث ثلاث مرات متتالية.

في 3 أغسطس 2026، أعلنت Zenity عن Series C بقيمة 125 مليون دولار بقيادة Norwest Venture Partners، مع SoftBank Vision Fund 2 وQumra Capital وHitachi Ventures وLG Technology Ventures. إجمالي التمويل ~185 مليون دولار. CEO Ben Kliger يقول: «As we enter the era of 1 billion agents, this investment allows us to bring AI agent security to many more organizations.»

المنصة تُغطي وكلاء Microsoft Copilot وChatGPT Enterprise وGemini وClaude وCodex وCursor وAWS Bedrock وAgentCore وMicrosoft Foundry وGoogle Vertex AI. الفرق عن أمان AI تقليدي: Zenity يحمي ما يفعله الوكيل لا النموذج فقط — prompt injection، data exfiltration، unauthorized tool calls.

Tech Startups وصف Zenity كـ «securing the coming wave of 1 billion AI agents». الشركة تُخطّط لتوسيع Zenity Labs وحضورها في أوروبا وAsia Pacific. للمبدعين العرب: كل bank وgovernment entity في MENA تُطلق Copilot agents — consulting لـ agent security posture وcompliance workshops فرصة ذهبية قبل أن تُصبح mandatory.

💡 كيف تربح من Zenity وثورة AI Agent Security؟

  • Agent security assessment: تدقيق posture للوكلاء في M365/Copilot — 8000–40000 دولار/مشروع.
  • Security policy design: بناء guardrails وapproval workflows — 5000–30000 دولار.
  • دورات «AI Agent Security»: workshop لفرق CISO — 199–999 دولار.
  • Managed agent governance retainer: مراقبة وتحديث policies — 2500–15000 دولار/شهر.

Obsidian Security: 85 مليون دولار — حوكمة الوكلاء داخل تطبيقات SaaS قبل فوات الأوان!

داخل تطبيقات SaaS التي تُشغّل أعمالك، الهويات غير البشرية تفوق البشر 144 إلى 1. Obsidian Security يُكتشف كل وكيل، يُخطّط MCP servers، ويمنع privilege escalation وdata access المفرط — في لحظة التنفيذ لا بعد الاختراق. 85 مليون دولار Series D — وتقييم 1.1 مليار دولار.

في 4 أغسطس 2026، أعلنت Obsidian Security عن Series D بقيمة 85 مليون دولار بقيادة Crescent Cove Advisors، مع Greylock Partners وMenlo Ventures. إجمالي التمويل يتجاوز 200 مليون دولار. CEO Hasan Imam: «You cannot credibly govern agents if control only happens after misuse.»

المنصة تُغطي Microsoft Copilot Studio وSalesforce Agentforce وn8n وAnthropic Claude Code وCowork. قدرات جديدة: Agent Access Governance لـ Claude — تقييد permissions على production data، إدارة access للملفات الحساسة، منع unsanctioned MCP usage. أكثر من 60 من Fortune 500 يستخدمون Obsidian — و14 عميلاً ينفقون أكثر من مليون دولار سنوياً.

SiliconANGLE وصف Obsidian كـ «AI agents create cybersecurity's next major attack surface». يوم بعد Zenity — جولتان ضخمتان في 48 ساعة تُؤكدان: agent security = infrastructure layer جديد. للمبدعين العرب: MSPs وconsultants في cybersecurity يمكنهم إضافة «Agent Runtime Governance» كخدمة premium للعملاء enterprise.

💡 كيف تربح من Obsidian Security وثورة Runtime Governance؟

  • MCP server inventory & audit: mapping كامل للـ MCP في المؤسسة — 6000–35000 دولار.
  • Claude/Copilot governance setup: تطبيق runtime guardrails — 10000–50000 دولار/مشروع.
  • Non-human identity consulting: استراتيجية IAM للوكلاء — 8000–40000 دولار.
  • دورات «Agent Runtime Security»: للـ security engineers — 299–1199 دولار.

Sapiom: 35 مليون دولار — Router وStudio وRuntime لـ «الترليون وكيل» القادم!

بين demo يعمل على laptop ووكيل production يُشغّل 100000 run يومياً — فجوة infrastructure. Sapiom يملأها: Router يختار أرخص model مناسب لكل request، Agent Studio يبني ويختبر الوكلاء محلياً، وRuntime يُشغّل production مع memory وsecrets وrecovery. 35 مليون دولار Series A من Dragonfly — 270 مليون transaction في 6 أشهر.

في 5 أغسطس 2026، أعلنت Sapiom عن Series A بقيمة 35 مليون دولار بقيادة Dragonfly، مع Accel وGradient وCoinbase Ventures وAnthropic وMenlo Ventures. إجمالي التمويل 50 مليون دولار — 11 شهراً من التأسيس. CEO Ilan Zerbib: «Our mission is to unlock the next trillion agents.»

Sapiom Router — endpoint متوافق مع OpenAI، يُوجّه كل request لأفضل model مسموح (cost + quality + latency + policy). عميل واحد خفّض inference costs 75%. Agent Studio — build, test, inspect, deploy مع context من codebase. Runtime — sandboxes, memory, secrets, scheduled triggers, automatic recovery.

المنصة تُعالج 270 مليون+ transaction و100000+ agent run يومياً. Haseeb Qureshi (Dragonfly) ينضم للـ board. للمبدعين العرب: agencies تبني agents للعملاء يمكنها white-label Sapiom Router — cut inference costs 50–75% وcharge margin. دورات «Agent Infrastructure» وconsulting لـ migration من OpenAI مباشرة = recurring revenue.

  • Cost optimization audits: تحليل inference spend وتطبيق routing — 3000–15000 دولار.
  • Agent Studio training: bootcamp لبناء production agents — 199–899 دولار.
  • Managed Runtime retainer: تشغيل وصيانة agents في production — 2000–12000 دولار/شهر.
