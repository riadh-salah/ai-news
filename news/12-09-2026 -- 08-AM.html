AWS Bedrock AgentCore: واجهات HTML تفاعلية داخل المحادثة — MCP Apps من الكتالوج إلى الحجز دون vendor lock-in!

«الوكيل يُجيب بنص — بينما العميل يريد زراً يحجز ويُحدّث الحالة فوراً». في 12 سبتمبر 2026، أطلقت Amazon Web Services Amazon Bedrock AgentCore: منصة لبناء ونشر وكلاء AI تفاعليين تدعم معيار MCP Apps — حيث تُعرض عناصر HTML تفاعلية مباشرة داخل مضيفي AI مثل ChatGPT وClaude، لا مجرد ردود نصية.

المشكلة التي حلّتها: المؤسسات تريد واجهات غنية داخل المحادثة — تصفح كتالوج، حجز خدمة، متابعة حالة — لكن كل مضيف AI يفرض نموذجاً مختلفاً. AgentCore يُوحّد الطبقة: AgentCore Runtime — بيئة serverless معزولة جلسةً لاستضافة تطبيقات MCP؛ AgentCore Gateway — endpoint واحد آمن يكشف التطبيقات للوكلاء عبر Model Context Protocol؛ discovery للأدوات والموارد يُمكّن widgets مدمجة في واجهة المحادثة.

القدرات الأساسية: interactive HTML widgets داخل chat — تجاوز النص البسيط؛ session-isolated runtime — أمان enterprise؛ MCP Apps standard — توافق عبر مضيفي AI؛ single secure endpoint عبر Gateway؛ تصفح كتالوجات وحجز خدمات وعرض تحديثات حالة من داخل المحادثة؛ AWS تُطلق أيضاً Amazon Q desktop للمؤسسات لكبح «shadow AI» — استخدام AI غير مصرّح به.

للمبدعين العرب: كل e-commerce وbank وtravel platform في MENA تبني conversational commerce — AgentCore MCP Apps deployment packages وArabic widget playbooks وmanaged agent UI retainers فرصة enterprise premium. «Rich UI inside chat» = category جديد — consultants الذين يُصمّمون MCP Apps مبكراً يفوزون بعقود transformation طويلة.

Zscaler Agentic SOC: أمن بسرعة الآلة — وكلاء AI يُحتوون هجمات AI قبل أن تتفشّى!

«المهاجمون يستخدمون AI لتسريع الهجوم — بينما SOC التقليدي يتحرك بسرعة البشر». في 12 سبتمبر 2026، أعلنت Zscaler (NASDAQ: ZS) عن Agentic SOC: نهج عمليات أمنية مُصمّم للعصر AI-first — يكتشف ويحقّق ويستجيب للتهديدات بسرعة الآلة، لا مجرد إضافة AI فوق أدوات قديمة.

المشكلة التي حلّتها: threat actors يُسرّعون الهجمات بالAI؛ SOC التقليدي يعجز عن correlate وinvestigate وremediate بسرعة كافية. Agentic SOC يُعيد بناء العمليات من الصفر: AI-first architecture — وكلاء متخصصون لا chatbot فوق SIEM؛ شراكة مع Anthropic وOpenAI — frontier models + threat intelligence ملكية Zscaler + zero trust telemetry؛ reasoning أعمق ودقة أفضل وexplainability أقوى من نموذج واحد.

القدرات الأساسية: proactive exposure reduction — تقليل الثغرات قبل الاستغلال؛ extend security team capabilities — وكلاء يُكملون البشر لا يُستبدلونهم؛ contain AI-driven attacks — احتواء بسرعة الآلة؛ closed-loop remediation — من الكشف إلى الإصلاح تلقائياً؛ inline telemetry — رؤية unmatched عبر الشبكة؛ متاح عالمياً الآن عبر zscaler.com/solutions/agentic-secops.

القدرات الأساسية: AES-256-GCM encryption — مفاتيح محادثة تُشفّر لكل participant؛ optional price tag للـ cold outreach — رسوم لمرة واحدة ثم الجلسة مجانية؛ Node.js وDeno — React components وHTML widgets جاهزة؛ MCP server — coding agents يتفاعلون مباشرة؛ attachments: صور 10MB، صوت 25MB، فيديو 100MB؛ متاح على GitHub مفتوح المصدر.
