الخبر الأول

oMLX: خادم LLM أصلي لـ Mac يُقطع زمن انتظار الوكلاء من 90 ثانية إلى 5 — KV cache على SSD وOpenAI وAnthropic APIs جاهزة!

«Claude Code على نموذج محلي يُجمّد 90 ثانية كلما تغيّر السياق — oMLX يُنهي هذه الكابوس». في 31 أغسطس 2026، احتل oMLX المركز الثاني Product of the Day على Product Hunt — خادم استدلال LLM أصلي لـ macOS مبني على MLX، يُحوّل Mac بـ Apple Silicon إلى endpoint محلي سريع لوكلاء الترميز.

المشكلة التي حلّتها: Ollama وLM Studio يُخزّنان KV cache في RAM — عندما يُغيّر coding agent السياق (وهذا يحدث عشرات المرات في الجلسة)، يُعاد حساب كل شيء من الصفر. Time-To-First-Token يصل 30–90 ثانية — workflow مُكسّر. oMLX يُخزّن كل cache block على SSD بصيغة safetensors: بنية ثنائية الطبقات — hot blocks في RAM، cold blocks على SSD مع LRU — عندما يعود الوكيل لسياق سابق، يُستعاد من القرص في milliseconds لا recompute.

القدرات الأساسية: continuous batching حتى 4.14× سرعة عند 8 طلبات متزامنة، OpenAI-compatible وAnthropic-compatible APIs تُسقط مباشرة في Claude Code وCursor وOpenClaw، دعم text وvision وOCR وembedding وreranker models، تطبيق menu bar أصلي Swift (لا Electron)، Apache 2.0 مفتوح المصدر. M3 Ultra 512GB: TTFT أقل من 5 ثوانٍ على contexts طويلة.

للمبدعين العرب: كل AI dev وagency في MENA يُريد privacy وسرعة على Mac — oMLX setup packages وArabic local-AI consulting وmanaged inference retainers فرصة developer-tools premium. «Local-first agent speed on Apple Silicon» vertical ينمو — oMLX تُكافئ teams التي تُريد sovereignty دون انتظار 90 ثانية.

Superagent: Claude Code للجميع — تطبيق Mac يُعطي وكيلك متصفحاً حقيقياً ومحاكي iOS وworktrees وiPhone pairing!

«العمل مع coding agent يجب أن يشبه تطبيق Mac جيداً — لا terminal». في 30 أغسطس 2026، احتل Superagent مكاناً بارزاً على Product Hunt بـ 106 upvote — بيئة macOS مفتوحة المصدر تُعطي وكيل AI مثل Claude Code «حاسوباً» كاملاً: متصفح حقيقي، iOS Simulator، ملفات، board، وroutines على timer.

المشكلة التي حلّتها: Claude Code في terminal قوي — لكن بلا واجهة بصرية دائمة، بلا متصفح يُسجّل دخولك، بلا محاكي iOS للاختبار، وبلا persistence عبر restarts. Superagent يُشغّل كل شيء محلياً 100%: chats في sidebar قابلة للتجميع، تبقى بعد إعادة التشغيل، كل chat على git worktree منفصل، pair iPhone والعمل يتبعك encrypted end-to-end. لا حساب، لا server، لا فاتورة ثانية.

القدرات الأساسية: browser يقوده الوكيل على sessions مسجّلة دخولك، iOS Simulator يُنقر ويُمرّر، filesystem access، board للمهام، routines مجدولة، model-agnostic (Claude Code الآن، Codex وAntigravity على roadmap). مفتوح المصدر على superagent.computer — binaries مجانية.

للمبدعين العرب: كل iOS/macOS dev shop وAI agency في MENA يُريد agent experience أفضل — Superagent setup packages وArabic mobile-agent workflows وmanaged dev-environment retainers فرصة premium. «Visual agent IDE for Mac» vertical ينمو — Superagent تُكافئ builders التي تُريد local-first power.

💡 كيف تربح من Superagent وثورة واجهة الوكلاء البصرية؟

  • Superagent team setup packages: إعداد workspaces وagents للفرق — 1000–9000 دولار/فريق.
  • Mobile-agent workflow design: تصميم workflows iOS/macOS — 1800–15000 دولار/workflow.
  • Managed agent IDE retainers: إدارة بيئات agents شهرياً — 2000–18000 دولار/شهر.
  • دورات «Build with Superagent on Mac»: bootcamp للمطورين — 39–249 دولار.

Olostep: حوّل الويب إلى بيانات نظيفة للـ AI — scrape وcrawl وmonitor وanswers عبر API وMCP وCLI واحد!

«الوكيل يحتاج الويب — لا HTML فوضوي». في 30 أغسطس 2026، احتل Olostep المركز الثالث Product of the Day على Product Hunt بـ 219 upvote — بنية تحتية بيانات الويب للمستخدم الثاني: AI agents — API واحد للبحث والزحف والاستخراج والمراقبة والتنظيم.

المشكلة التي حلّتها: AI teams تبني scraping infrastructure من الصفر — proxies وJavaScript rendering وanti-bot وbatch processing — أو تدفع لخدمات باهظة بـ retrieval rate منخفض. Olostep يُحوّل أي URL إلى Markdown أو JSON أو HTML نظيف جاهز للـ LLM: /scrapes لصفحة واحدة، /crawls لموقع كامل، /answers لإجابات مُستندة للمصادر، /agents لworkflows بلغة طبيعية، /monitors لتتبّع أسعار ووظائف وتغييرات DOM.

القدرات الأساسية: batch حتى 10000 URL في 5–7 دقائق، full JS rendering وresidential proxies، MCP server لـ Cursor وClaude Code وWindsurf، CLI وSDKs وintegrations مع LangChain وn8n وZapier، self-healing extractors لـ JSON مُtyped. Use cases: market research وlead gen وcompetitive intelligence وRAG grounding — «Infrastructure for the Web's second user».

للمبدعين العرب: كل AI startup وconsulting firm في MENA يحتاج web data — Olostep integration packages وArabic research pipelines وmanaged data-enrichment retainers فرصة infrastructure premium. «Web data API for agents» vertical ينمو — Olostep تُكافئ teams التي تُريد scale دون DevOps scraping.

Murfy AI: اكتب وراجع وانشر على arXiv 10× أسرع — فريق AI agents لـ LaTeX وpeer review وBeamer slides!

«الباحثون يستخدمون AI لكل شيء — إلا كتابة الورقة نفسها». في 30 أغسطس 2026، احتل Murfy AI المركز الخامس Product of the Day على Product Hunt بـ 181 upvote و5.0 rating — محرر LaTeX AI-native يُجمّع فريق agents للـ workflow البحثي كاملاً: كتابة، مراجعة، إصلاح compile errors، والنشر.

المشكلة التي حلّتها: Copilot للكود، Elicit للمراجعات، ChatGPT للأفكار — لكن كتابة الورقة في Overleaf بلا AI حقيقي مُدمج. Murfy ليس chatbot مُلحقاً — agents تعمل معك في السياق: تُ drafts معك، تُراجع الورقة بـ multi-agent peer review (readers متعددون + cross-check)، تُصلح LaTeX compile errors فوراً، تُتحقق من المراجع، وتُولّد Beamer slides في دقائق.

القدرات الأساسية: تعاون real-time بcollaborators غير محدودين (مجاناً)، compilation engine سريع، version history كامل على free tier، AI credits للمراجعة والترجمة (Korean→English)، smart code completion. بديل Overleaf مع AI review وerror fixing مُدمج — «Write, review, and publish to arXiv 10x faster».
