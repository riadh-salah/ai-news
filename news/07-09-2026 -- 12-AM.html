QVeris Agent Toolkit: MCP واحد لـ 10,000+ قدرة — discover وinspect وcall بلا تكديس integrations!

«كل أداة جديدة تعني schema جديد وauth جديد وcontext window أثقل — QVeris يُنهي هذا الجحيم». في 6 سبتمبر 2026، أطلقت QVeris Agent Toolkit مفتوح المصدر (MIT) — شبكة routing للقدرات تُمكّن الوكلاء من اكتشاف وتنفيذ أكثر من 10,000 أداة وAPI ومصدر بيانات حي عبر واجهة MCP صغيرة ومستقرة.

المشكلة التي حلّتها: agents قوية في التفكير لكنها تغرق في integrations — كل MCP server يضيف schemas وauthentication وerror handling. QVeris يعرض ست أدوات canonical فقط: discover (بحث بلغة طبيعية)، inspect (params ومعدل نجاح وأمثلة)، probe (تحقق بلا تنفيذ)، call (تنفيذ)، usage_history، وcredits_ledger.

القدرات الأساسية: MCP server (@qverisai/mcp v0.14.0) لـ Cursor وClaude Desktop وCopilot وCline وRoo Code؛ CLI (@qverisai/cli) الأكثر كفاءة في tokens؛ Python SDK وTypeScript SDK؛ agent skills وrecipes جاهزة؛ Hosted MCP Streamable HTTP بدون local process؛ 15+ فئة (مالية، بيانات، خدمات)؛ discover مجاني مع billing structured عند call.

للمبدعين العرب: كل فريق يبني agents enterprise — QVeris integration packages وArabic capability routing playbooks وmanaged agent toolkit retainers فرصة infra premium. «Unified capability routing» vertical ينمو — QVeris تُكافئ teams التي تُسلّم discover-to-call pipelines لا hard-coded endpoints.

AgentRender: API عام للوكلاء — screenshot وPDF وextract من أي URL مع MCP وإيصالات render!

«الوكيل يحتاج أن يرى الصفحة — لا أن يُخمّن HTML». في 6 سبتمبر 2026، أطلق Corbin Vachal AgentRender — API demo عام يُحوّل URL عام إلى screenshot أو PDF أو structured page extract، مع أدوات MCP first-class و«render receipts» للوكلاء.

المشكلة التي حلّتها: agents تحتاج visual context من web pages لكن screenshot APIs التقليدية marketing-focused بلا agent ergonomics — لا receipts ولا MCP native. AgentRender: POST /v1/screenshot، /v1/pdf، /v1/extract مع Chromium حقيقي عبر Playwright.

القدرات الأساسية: MCP tools للوكلاء؛ render receipts لكل عملية؛ Free tier 150 render/شهر؛ Starter 17 دولار (2000 render)؛ Growth 79 دولار (10,000)؛ Scale 259 دولار (50,000)؛ waitlist لمفاتيح مجانية؛ demo API على Fly.io؛ built for agents لا screenshot-only marketing.

للمبدعين العرب: كل agent builder وautomation shop — AgentRender wrapper packages وArabic web scraping playbooks وmanaged render retainers فرصة infra premium. «Agent-native rendering» vertical ينمو — AgentRender يُكافئ teams التي تُسلّم visual agent workflows لا brittle HTML parsing.

LlamaIndex Extract Turbo: أسرع tier لاستخراج المستندات — 4x أسرع و0.5 ثانية/صفحة للمستندات الطويلة!

«المستخدم رفع 64 فاتورة — إما تُعالج الآن أو يغادر». في 3 سبتمبر 2026، أطلقت LlamaIndex Extract Turbo في beta — أسرع tier استخراج VLM-powered، مُصمّم لworkflows latency-sensitive حيث كل ثانية تحسب.

المشكلة التي حلّتها: document extraction tools latency تتناسب linearly مع طول المستند — users يغادرون قبل اكتمال المعالجة. Extract Turbo يُزيل parsing pass منفصل: على ExtractBench 4x+ أسرع من Cost Effective mode؛ median 3.7 ثانية/صفحة للمستندات القصيرة؛ ~0.5 ثانية/صفحة للمستندات 64+ صفحة؛ F1 value 0.84.

القدرات الأساسية: tier turbo على LlamaExtract v2 REST API؛ 35 credits/صفحة؛ VLM-powered extraction بلا parse step منفصل؛ text-level citations (بدون bounding boxes)؛ PDF وimage inputs؛ MCP server للـ LlamaParse Platform؛ agent skills وn8n node متاحة.

Cursor Self-Hosted Machines: Cloud Agents على Modal وE2B — الكود يبقى داخل شبكتك!

«الوكيل ذكي — لكن secrets وsource code لا يجب أن يغادرا الشركة». في 2 سبتمبر 2026، أطلقت Cursor Self-Hosted Machines — Cloud Agents تنفّذ tool calls على hardware تملكه أنت بينما inference يبقى في Cursor cloud.

المشكلة التي حلّتها: enterprise teams تريد agentic coding لكن code وbuild outputs وsecrets لا يمكن أن تمر عبر Cursor-hosted sandboxes. Self-Hosted Machines: My Machines (laptop/VM شخصي) وTeam Pools (worker queues enterprise) — workers تتصل outbound HTTPS بلا inbound firewall holes.

القدرات الأساسية: 8 sandbox providers (AWS Lambda، Cloudflare، Coder، Daytona، E2B، Modal، Namespace، Vercel)؛ computer use على Linux وMac workers؛ pools تتوسع عند الطلب وتتقلص عند disconnect؛ hibernate idle machines؛ Modal integration: sandbox مُخصّص لكل Cloud Agent session؛ Enterprise plan + service account API key.

للمبدعين العرب: كل enterprise وbank وgov tech — Cursor self-hosted setup packages وArabic secure agent playbooks وmanaged private cloud agent retainers فرصة security premium. «Private agent infrastructure» vertical ينمو — Cursor تُكافئ integrators التي تُسلّم network-contained agents لا cloud-only demos.
