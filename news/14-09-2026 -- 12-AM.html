Bolt Forge: وكيل Bolt.new بالموديلات المفتوحة — GLM 5.3 وKimi K3 وDeepSeek v4 مع 50× استخدام Pro!

«تريد بناء تطبيق كامل دون أن تُقفل على موديل مغلق واحد؟». في 14 سبتمبر 2026، أطلقت Bolt.new Bolt Forge — وكيل بناء تطبيقات يعمل حصرياً على موديلات مفتوحة المصدر، ضمن نافذة research preview حتى 14 أكتوبر 2026، مع عرض خاص: حتى 50× استخدام إضافي على خطة Pro بلا تكلفة إضافية.

المشكلة التي حلّتها: منصات no-code AI كانت تربط المطور بمزود واحد — تكلفة، حدود، وصعوبة تدريب نماذج محلية. Forge يُشغّل افتراضياً GLM 5.3 Flash مع خيارات GLM 5.3 وKimi K3 وDeepSeek v4 Pro تجريبياً — كلها قابلة للاختيار من الواجهة.

القدرات الأساسية: شراكة مع Arcee AI لتدريب موديل open-weight بحجم تريليون معامل؛ المستخدمون يختارون مشاركة جلسات بناء مجهولة الهوية (اتفاقية معالجة بيانات موقّعة)؛ بعد 14 أكتوبر يستمر Forge كمختبر مفتوح لكن ينتهي مضاعف الـ 50× ونافذة التدريب الأولى؛ Pro الحاليون يبدأون فوراً دون شراء إضافي.

للمبدعين العرب: كل agency وproduct studio ومسابقات hackathon في MENA — Bolt Forge onboarding packages وArabic prompt libraries للموديلات المفتوحة و«open-model app factory» retainers فرصة builder premium. «Build on open weights + share-to-train» = نموذج اقتصادي جديد — من يُ package قوالب SaaS عربية على Forge يفوز بسرعة إطلاق.

Sesame على iOS: Maya وMiles وSimone وCharlie — محادثة طبيعية وذاكرة ومسار نحو نظارات 2027!

«ChatGPT يُجيب بسرعة — لكنه لا يُحسّ وكأنه يستمع». في 14 سبتمبر 2026، أطلقت Sesame — startup من مؤسسي Oculus وفرق VR سابقة في Meta — معاينة عامة لتطبيق iOS بوكلاء محادثة: أربعة شخصيات (Maya، Miles، Simone، Charlie) بصوت وشخصية وذاكرة مستقلة.

المشكلة التي حلّتها: chatbots تتعامل مع كل سؤال كجلسة منفصلة؛ الصوت يبدو robotic؛ البحث البصري ضعيف. Sesame يُبقي تدفق المحادثة حتى عند تأخر المعالجة، يُضيف بطاقات بحث بصري، ملاحظات، وضع نصي، استفسارات deep-dive، وincognito للخصوصية — بناءً على مليون+ مستخدم في Research Preview السابق (جولة Series B ~250 مليون دولار مع Sequoia).

القدرات الأساسية: متاح في 39 دولة مجاناً حالياً مع waitlist محتمل؛ Android لاحقاً؛ الرؤية: وكلاء يُنفّذون إجراءات نيابة عنك وليس محادثة فقط؛ هدف نظارات ذكية 2027 — التطبيق خطوة أولى نحو embodied AI.

للمبدعين العرب: سوق voice-first وcompanion apps في الخليج ومصر ينمو — Sesame-style Arabic persona packages وUX consulting للـ aging وeducation و«voice brand» retainers فرصة consumer AI premium. «Personality + memory + action agents» = category — من يُ localize أربع شخصيات للثقافة العربية يبني IP نادر قبل موجة eyewear.

💡 كيف تربح من Sesame وثورة الوكلاء الصوتيين على الجوال؟

  • Voice agent persona packages: شخصيات عربية + scripts + QA — 3500–28000 دولار/علامة.
  • Conversational UX consulting: flows + incognito + accessibility — 4000–35000 دولار/عميل.
  • Managed companion app retainers: content + analytics + localization — 900–7500 دولار/شهر.
  • دورات «Design Natural Voice Agents like Sesame»: bootcamp — 39–199 دولار.

AllSpark Iris-mini وIris-pro: وكلاء بحث مفتوحة الوزن على Qwen3 — Iris Harness وكود التقييم كاملاً!

«Perplexity قوي — لكن أين weights وrecipe التدريب؟». في 13 سبتمبر 2026، أعلنت مختبرات AllSpark الصينية عن Iris-mini وIris-pro — وكلاء بحث open-weight مبنيان على Qwen3، يتصدران فئتهما في أربعة benchmarks للبحث المستقل وفق الفريق.

المشكلة التي حلّتها: scores منشورة دون disclosing إدارة السياق؛ وكلاء chat عامون يفشلون في web research طويل. الإصدار يتضمن أوزاناً على Hugging Face، Iris Harness (حلقة الوكيل، أدوات، استراتيجيات context، benchmarks + scripts)، يعمل مع أي endpoint متوافق OpenAI — pipelines التدريب «قريباً» للتحقق المستقل.

القدرات الأساسية: Iris-mini وIris-pro لحجمين مختلفين؛ paper يُ argument أن scaffolding إدارة السياق — لا الوزن وحده — يُفسّر فجوة الأداء؛ تحسينات claimed على tool use عام ومكتبية حتى دون تدريب صريح — يُراقب عند إ release pipeline؛ مفتوح للفرق التي تبني research agents داخل MENA datacenters.

للمبدعين العرب: كل media house وlegal tech وdue diligence في المنطقة — Iris deployment packages وArabic search agent playbooks وmanaged open-research retainers فرصة enterprise premium. «Open search agent + harness» = بديل self-hosted لـ closed APIs — integrators الذين يُ host على sovereign cloud يفوزون ب contracts حكومية.

💡 كيف تربح من Iris-mini/pro وثورة البحث الوكيلي المفتوح؟

  • Iris self-hosted packages: Hugging Face + harness + GPU sizing — 6000–55000 دولار/مشروع.
  • Research agent consulting: benchmarks + Arabic corpus tuning — 5000–48000 دولار/عميل.
  • Managed open-search retainers: updates + eval + compliance — 3500–28000 دولار/شهر.
  • دورات «Deploy Open Search Agents with Iris Harness»: bootcamp — 49–249 دولار.

AWS Pizza Bot: صندوق وارد للوكلاء الخلفيين — DeepAgents وLangGraph وMCP وموافقات بشرية!

«الوكيل يعمل ساعات — وأنت تُحدّث terminal كل دقيقة؟». في 10 سبتمبر 2026، أعلن فريق AWS عن Pizza Bot — تطبيق desktop مفتوح المصدر (Apache 2.0) يُ simulates inbox بريد لإدارة background AI agents؛ استخدمه آلاف داخل Amazon قبل إعادة بنائه كمشروع مجتمعي مستقل على GitHub.

المشكلة التي حلّتها: long-running agents تُرهق المستخدم بـ polling؛ فقدان الحالة عند disconnect. Pizza Bot يُسلّم المهام المكتملة كـ threads غير مقروءة، يُبرز ما يحتاج قراراً بشرياً، وActivity panel يُظهر handoffs لوكلاء متخصصين مع tool use؛ runtime على DeepAgents + LangGraph مع checkpoints للاستئناف بعد موافقة أو انقطاع.

القدرات الأساسية: self-hosted بلا SLA AWS — community project؛ دعم مزودي موديل متعددين وMCP وskills؛ «غياب المستخدم» مبدأ تصميم — الوكيل يُكمل دون حضورك؛ persistence محلياً في DB وملفات؛ مناسب لفرق ops وstartups التي تُشغّل agent swarms.

للمبدعين العرب: كل DevOps وBPO وoperations-heavy SaaS — Pizza Bot deployment packages وArabic approval workflow templates وmanaged agent-inbox retainers فرصة automation premium. «Email UX for agents» = pattern قابل للنسخ — consultants الذين يُ integrate MCP + human-in-the-loop يبيعون ops transformation.

💡 كيف تربح من Pizza Bot وثورة صندوق الوارد للوكلاء؟

  • Pizza Bot deployment packages: self-host + MCP + approval flows — 4500–38000 دولار/مشروع.
  • Agent ops consulting: LangGraph patterns + specialist handoffs — 5500–50000 دولار/عميل.
  • Managed agent-inbox retainers: monitoring + runbooks — 2800–22000 دولار/شهر.
  • دورات «Run Background Agents with Pizza Bot»: bootcamp — 39–199 دولار.
