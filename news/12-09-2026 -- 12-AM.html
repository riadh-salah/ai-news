Cursor Projects: منسّق وكلاء يُدير آلاف subagents — سياق يستمر أشهراً وCI يُصلَح تلقائياً!

«محادثة واحدة تنتهي — لكن الميزة تحتاج عشرين PR على مدى شهرين». في 10 سبتمبر 2026، أطلقت Cursor Projects: طبقة عمل أعلى من chat، حيث coordinator agent لا يكتب الكود بنفسه بل يُوجّه أسطولاً من الوكلاء الفرعيين — مع سياق يستمر أشهراً وmemories مشتركة عبر كل آلة.

المشكلة التي حلّتها: era الوكلاء الأولى = prompt واحد → PR واحد. لكن migrations وfeatures الكبيرة وrefactors تحتاج long-horizon coordination — من يتذكر قرارات الأسبوع الماضي؟ من يُصلح CI عند merge؟ Projects يُجيب: coordinator يفهم codebase وpreferences ويُفوّض التنفيذ؛ كل agent يحصل على memories تتزامن عبر machines؛ إذا فشل agent، coordinator يُعيد التوجيه دون أن تُعيد الشرح.

القدرات الأساسية: coordinator + subagent fleet — responsive دائماً لأنه يُفوّض لا ينفّذ؛ shared memories — lessons learned تُورَّث للأسطول؛ Subscriptions — مراقبة Slack، جدولة cron، متابعة PRs وإصلاح CI تلقائياً؛ beta rolling out لجميع المستخدمين من شريط التنقل الأيسر؛ مثالي للـ migrations والfeatures متعددة PRs والعمل أثناء غيابك.

للمبدعين العرب: كل software house وproduct team في MENA يُخطّط لـ agentic development — Cursor Projects setup packages وArabic coordinator playbooks وmanaged coding agent retainers فرصة dev premium. «Third era of software development» = fleets of agents — consultants الذين يُصمّمون Project workflows مبكراً يفوزون بعقود enterprise طويلة.

Storyblok Agents: تحدّث مع محتواك داخل CMS — وكلاء مجدولة وMCP Server للخارج!

المشكلة التي حلّتها: headless CMS = قوة للمطورين لكن workflows يدوية للمسوقين. Storyblok Agents يُحوّل CMS إلى conversational workspace: اكتشاف duplicate content وmissing translations وcontent needing work؛ بناء custom agents لأي مهمة متكررة وجدولتها تلقائياً؛ اختيار AI provider وmodel أو BYO credentials للتحكم الكامل في token spend.

القدرات الأساسية: conversational content research — stale، duplicated، untranslated في جملة واحدة؛ scheduled agents — workflows تعمل دون تدخل؛ permission-based execution — agents تعمل ضمن صلاحياتك وموافقتك؛ Storyblok MCP Server — أي agent خارجي يصل لـ workspace بشكل structured؛ متاح عبر Storyblok Labs على Growth plans وما فوق مع demo تفاعلي.

Orloj: Kubernetes للوكلاء — YAML وcontainers وحوكمة fail-closed من demo إلى production!

«الـ demo agent يعمل — لكن production يحتاج retries وobservability وrollback». Orloj يُقدّم agent infrastructure as code: orchestration runtime مفتوح المصدر حيث تُعرّف agents وtools وpolicies وworkflows في YAML — وOrloj يُجدول وينفّذ ويحكم عليها كـ Kubernetes للوكلاء.

المشكلة التي حلّتها: LangChain وCrewAI = بناء agents؛ لكن production reliability = glue code لا نهاية له. Orloj يُعالج الفجوة: declarative manifests للagents والpolicies وDAG workflows؛ tools في isolated containers مع image pins صريحة؛ fail-closed governance على execution layer؛ lease-based scheduling مع dead-letter handling؛ orlojctl apply -f ./your-system/ — reconcile agents وgraph وgovernance وtasks في pass واحد.

القدرات الأساسية: YAML-first — agents، policies، DAG workflows؛ container isolation — أمان explicit؛ CLI apply/rollback — deployment آمن؛ horizontal scaling من laptop إلى cluster؛ 20 templates planned للuse cases شائعة؛ مفتوح المصدر — community contributions welcome؛ يكمّل LangChain/CrewAI لا يُنافسها — orchestration plane منفصل.

للمبدعين العرب: كل fintech وhealthtech وenterprise في MENA ينتقل من agent POC إلى production — Orloj deployment packages وArabic YAML workflow playbooks وmanaged agent fleet retainers فرصة infra premium. «Demo agent → production agent fleet» = pain point universal — consultants الذين يُتقنون Orloj مبكراً يفوزون بعقود platform engineering.
