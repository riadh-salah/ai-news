Dial: رقم هاتف حقيقي لوكيل AI في 10 ثوانٍ — صوت وSMS وWhatsApp وiMessage من API واحد أو MCP!

«وكيلك يُنجز كل شيء — ثم يتوقف عند كود التحقق SMS». في 2 سبتمبر 2026، أُطلق Dial على Product Hunt (#5 يومياً، 147 upvote) — communication stack مُصمّم للوكلاء يُزوّد AI agents برقم هاتف حقيقي carrier-grade في ~10 ثوانٍ عبر REST API أو MCP server.

المشكلة التي حلّتها: agents تُبنى في دقائق لكن لا تستطيع الحصول على رقم هاتف — Twilio يتطلب 10DLC registration (10–15 يوم review) قبل أول SMS. Dial agent-native: رقم واحد يُتصل ويُرسِل SMS في 200+ دولة وWhatsApp في 180+ دولة وiMessage مع RCS/SMS fallback — webhook موحّد لكل القنوات.

القدرات الأساسية: provisioning فوري US/Canada/international، قراءة inbound verification codes (phone-gated signups لم تعد dead end)، MCP server يعمل مع Claude Code وCursor وOpenClaw، SDKs Node.js/Python، $5 free credit بلا بطاقة، $3/شهر per number، $0.13–0.22/دقيقة voice، $0.02/SMS. Use cases: booking by phone، supplier outreach، signup automation.
